# Terenske fotografije — test u stvarnim uslovima

Fotografije pojedinačnih pčela van dataseta: druge pozadine, kamere, osvetljenje.
Ovo je jedini test koji meri ono što korisnik aplikacije zaista radi.

- `varoa/`  — pčele na kojima se grinja jasno vidi
- `zdrava/` — pčele bez vidljive grinje

Oznaku određuje čovek gledajući fotografiju. Pokretanje:

    ./.venv/bin/python -m src.field_test

Prve dve fotografije su one koje je Medžid učitao u aplikaciju 06.10.2026.
